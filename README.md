# Background Remover / Background Studio source

Extracted from the CanvasCodex project. The main tool is in `src/components/backgroundStudio/BackgroundStudio.tsx` and the route wrapper is `src/pages/BackgroundRemoval.tsx`.

Included:
- Background removal workflow and editing canvas
- Templates, SVG import, fonts, text styling, shapes and logos
- Batch editing and Apply-to-all controls
- Project save/load and exports
- Required shared UI, editor controls and supporting libraries
- Bundled Background Studio public assets

This is a source extraction for the tool. It is kept separate from the full application so it can be copied or integrated independently. The original repository remains unchanged by this export.
